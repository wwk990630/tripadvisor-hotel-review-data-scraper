# TripAdvisor Hotel Review Data Scraper｜猫途鹰酒店评论爬虫与数据获取

[English](README.md)

这是一个通过自学和实际项目完成的 Python 猫途鹰酒店评论数据获取研究。仓库保留了长期探索中可复用的工程核心：结构感知解析、分页保护、隐私最小化断点、来源记录与公开发布检查。

## 包含内容

项目包含标准化评论记录、两类响应结构解析、GraphQL 与结构错误、重复页和提前空页检测、只保存 ID 与哈希的断点，以及人工成功/失败夹具。仓库不包含账号、cookies、授权材料、线上 query 标识、代理配置、私人抓包或实际采集数据集。

## 问题与否决路线

依赖 cookies 的一次性脚本即使偶尔成功，也无法说明后续失败究竟来自会话过期、GraphQL 错误、结构变化还是分页问题。直接公开私人流水线的路线被否决，因为其中存在短期凭证与真实研究数据。公开版本保留经过测试的契约，不重新分发敏感证据。详见[问题分析](docs/problem-solving.md)。
